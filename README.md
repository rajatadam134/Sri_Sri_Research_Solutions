# Sri Sri Research Solutions

Clinical Research Organization (CRO) and Site Management Organization (SMO) web platform.

## Overview
Web platform for Sri Sri Research Solutions, providing clinical trial management, hospital site infrastructure, CDSCO/ICH-GCP regulatory liaison, and AYUSH validation.

## Key Features
- **DNA Video Hero Integration**: Masked rotating DNA helix loop blended with brand Aubergine (`#453747`).
- **Interactive CRO/SMO Matrix**: End-to-end trial delivery, medical writing, site coordinator deployment.
- **Therapeutic Area Taxonomy**: 8 critical indication portfolios with category filters (Pharma & Biologics, Cardio & Metabolic, AYUSH).
- **Pan-India Site Network Hub**: Multi-centric hospital research capacity across major Indian healthcare clusters.
- **Ethics & Compliance Section**: CDSCO New Drugs and Clinical Trials Rules (2019) and ICH-GCP E6(R2) frameworks.
- **Secure Feasibility Portal**: Study intake form with protocol upload dropzone and mutual NDA request toggle.

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Zodiak (Display serif), Cabinet Grotesk (Stats/Eyebrows), Author (Body)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
Emits optimized static bundle to `dist/`.
